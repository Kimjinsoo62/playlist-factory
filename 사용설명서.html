플레이리스트 팩토리 사용설명서

장르 프리셋을 고르고 곡 수와 언어를 정한 뒤 ▶ 자동 생성 시작을 누르면, 곡 생성(병렬) → 라우드니스 정규화 → 이어붙이기 → 가사 자막 → 썸네일 → 1080p 영상 렌더링 → 유튜브 제목·설명·챕터 작성까지 한 번에 끝납니다. 음악 생성은 Treblo(구 Sonauto) API를 사용합니다. Powered by Treblo

1. 설치와 실행

  1. install.bat을 한 번 실행합니다. Node.js·Python·ffmpeg·git이 없으면 winget(Windows 앱 설치 관리자)으로 자동 설치를 시도하고(관리자 권한 창이 뜨면 [예]), Node 패키지와 Pillow를 설치합니다. 프로젝트가 git 저장소가 아니면(ZIP 다운로드·폴더 복사) GitHub에 연결해 [업데이트] 버튼을 쓸 수 있게 합니다. 방금 새로 설치된 프로그램은 새 창에서 적용되므로, 설치 후 START.bat을 새로 실행하세요.
  2. START.bat으로 실행합니다. Node.js나 의존성이 없으면 install.bat을 자동으로 호출합니다(창이 바로 닫히지 않고 안내가 남습니다). 브라우저가 자동으로 열립니다.
  3. 같은 네트워크의 다른 PC에서는 START 창과 화면 상단에 표시되는 http://IP주소:5177로 접속합니다. 접속이 안 되면 Windows 방화벽에서 Node.js의 사설 네트워크 접근을 허용하세요.
필수 프로그램: Node.js 18 이상, Python 3.10 이상(Pillow), ffmpeg(PATH 등록), git([업데이트] 버튼용). install.bat이 winget으로 자동 설치합니다. 수동 설치: winget install OpenJS.NodeJS.LTS, winget install Python.Python.3.12, winget install Gyan.FFmpeg, winget install Git.Git. winget이 없는 PC(오래된 Windows 10)는 각 공식 사이트에서 설치하세요.

2. Treblo API 키 발급과 입력

  1. treblo.com/developers에서 계정을 만들고 API 키를 발급받습니다. 무료 체험은 카드 등록 후 3,000크레딧(약 30곡)이 제공되며, 이후 월 $11(200곡) 플랜 또는 종량제(100크레딧당 약 $0.06)입니다.
  2. 앱 상단의 설정 버튼을 눌러 작곡 AI API 키 모달을 엽니다. Treblo 카드의 API 키 칸에 붙여 넣고 저장을 누릅니다. 키는 프로젝트 폴더의 config.json에만 저장되며(git 추적 제외) 화면에는 앞뒤 4자만 표시됩니다.
  3. 같은 카드의 크레딧 확인을 눌러 잔액이 표시되면 연결 성공입니다. 곡 하나에 100크레딧이 듭니다. 모델(v3/v2)과 동시 생성 수도 이 카드에서 바꿉니다. 키 삭제는 config.json 에서 키를 지웁니다.
  4. ● 활성화 / ○ 대기: 작곡 AI 키를 두 개(Treblo·Lyria) 등록했을 때 한 번에 하나만 활성으로 씁니다. 활성 소스가 새 작업의 기본 소스가 되고, 대기 소스는 소스 목록에서 "— 대기"로 표시되어 고를 수 없으며 작업 요청도 거부됩니다. 활성 카드의 ○ 대기를 누르면 다른 소스가 자동으로 활성이 됩니다(다른 소스에 키가 없으면 전환되지 않음). 활성 소스는 config.json 의 provider 값입니다.
웹앱 무료 정책과 API는 다릅니다. treblo.com 웹에서 무료로 만들고 내려받은 곡은 소스를 "로컬 폴더"로 바꿔 input/에 넣으면 나머지 과정(결합·자막·썸네일·렌더링)을 그대로 자동 처리합니다. 다만 웹에서 만든 곡의 상업적 이용 조건은 Treblo 이용약관 8조(Outputs)를 직접 확인하세요. API로 만든 곡은 API 약관에 따라 소유권과 수익화가 허용됩니다.

2-1. Google Lyria 키 (선택, 연주곡 전용)

  1. aistudio.google.com/apikey에서 Gemini API 키를 발급합니다. Lyria는 무료 티어가 없어 결제가 연결된 Google Cloud 프로젝트의 키여야 합니다. 곡당 $0.08(2026년 10월 기준, 프리뷰라 변동 가능)이 Google 결제 계정에 청구됩니다.
  2. 상단 설정 버튼 → Google Lyria 카드에 붙여 넣고 저장 → 키 확인을 누르면 모델 이름이 표시됩니다(확인은 과금되지 않음). 환경변수 GEMINI_API_KEY로도 전달할 수 있으며, 환경변수로 지정된 키는 모달에서 지울 수 없습니다.
  3. 소스에서 Google Lyria를 고르면 보컬 옵션이 자동으로 "연주곡"이 됩니다. 보컬곡 프리셋을 그대로 보내면 서버가 거부합니다.
Lyria는 왜 연주곡만? Lyria는 가사 텍스트는 돌려주지만 단어별 타이밍 데이터를 주지 않아 박자에 맞는 가사 자막을 만들 수 없습니다. 보컬곡은 Treblo 소스를 쓰세요. 또 Lyria 출력에는 SynthID 워터마크(비가청)가 항상 들어가며, Gemini API 약관은 생성물 소유권을 주장하지 않지만 유튜브 수익화·Content ID 안전성을 보장하지는 않습니다. 업로드 전 Gemini API 약관을 확인하세요.

2-2. 메인 LLM 키 — Claude · OpenAI · Gemini 중 하나 (선택, 권장)

  1. 상단 설정 모달의 메인 LLM 구역에 세 카드가 있습니다. 쓸 제공자의 키를 발급받아 저장하고 키 확인을 누릅니다(확인은 토큰을 쓰지 않음). Claude는 platform.claude.com, OpenAI는 platform.openai.com, Gemini는 aistudio.google.com에서 발급합니다. Gemini 카드를 비워 두면 Lyria에 넣은 Google 키를 같이 씁니다. 환경변수 ANTHROPIC_API_KEY, OPENAI_API_KEY, GEMINI_API_KEY로도 전달할 수 있습니다.
  2. ● 메인으로를 누르면 그 제공자가 메인 LLM이 되고 나머지는 대기가 됩니다(설정 파일의 llm.provider). 키가 둘 이상 있을 때 언제든 바꿀 수 있습니다. 메인 카드의 ○ 대기를 누르면 키가 있는 다른 제공자가 메인이 됩니다.
  3. 카드마다 모델 두 칸이 있습니다. 모델은 프리셋 생성처럼 품질이 중요한 작업에, 경량 모델은 작업마다 도는 번역·사진 선별에 씁니다. 모델 id는 제공자가 수시로 바꾸므로 자유 입력이며, 모델 목록 버튼을 누르면 그 키로 쓸 수 있는 id가 입력칸의 제안 목록(▼)에 들어옵니다. 비워 두면 기본값(Claude: Opus 5.5/Haiku 5.5, OpenAI: gpt-5.4/gpt-5.4-mini, Gemini: gemini-3.6-flash/gemini-3.5-flash-lite)을 씁니다. 기본 id가 더 이상 없다는 오류가 나면 모델 목록에서 골라 저장하세요.
  4. 이 키가 있으면 세 가지가 자동으로 켜집니다.
    • 한글 요청 → 영어 번역: 작업을 시작할 때 프리셋의 한국어 상세 설명과 "추가 프롬프트"의 한국어를 영어로 번역해 작곡 AI에 보냅니다. 번역문은 작업 폴더의 translation.json에 남습니다. 키가 없으면 한국어가 그대로 전달됩니다(Treblo는 한국어도 이해하지만 영어가 더 정확합니다).
    • 새 장르(프리셋) 만들기: 프리셋 모달의 ✨ AI로 영어 프롬프트 자동 생성 버튼이 메인 LLM을 씁니다(카드의 "모델"이 여기에 적용됨).
    • 배경 사진 기획·선별: 4-5 참고.
  5. 비용: 프리셋 생성은 "모델"로 한 번에 수십 원 수준, 번역·사진 선별은 작업마다 "경량 모델"로 2~3회 호출되어 수 원 수준입니다(제공자별 단가는 각 사이트 참고).

4-2. 프리셋

프리셋에는 장르의 악기·템포·분위기가 음악 용어로 이미 들어 있어 고르기만 하면 됩니다. 한 플레이리스트의 모든 곡은 같은 프리셋을 써서 결이 흩어지지 않습니다. 기본 제공: 재즈 나이트, 네오소울 R&B, 하드록 드라이브, 로파이 스터디(연주곡), 시티팝 나이트, 어쿠스틱 발라드, 테토 무드, 올드팝 클래식(1960~80년대 올드팝 발라드).

프리셋 선택 옆 [설명·편집] 버튼을 누르면 모달이 열립니다. 여기서 한국어 상세 설명(분위기·악기·템포·보컬 톤)을 읽고 고칠 수 있고, "한국어 상세 설명을 곡 생성 프롬프트에 포함"이 켜져 있으면 그 내용이 영어 기본 프롬프트 뒤에 붙어 Treblo에 그대로 전달됩니다. 영어 프롬프트가 이미 있는 프리셋은 이 옵션이 꺼져 있습니다. 프롬프트가 설명을 번역한 것이라 둘 다 보내면 같은 내용이 두 번 들어가 장르 지시가 흐려지기 때문입니다. 프롬프트에 없는 내용을 설명에 덧붙였을 때만 켜세요. 아래 "최종 프롬프트 미리보기"에서 실제로 보내질 문장을 확인하세요. 보컬 성별(남성·여성·미지정. 지정하면 male vocalist/female vocalist 태그와 "Male/Female lead vocal" 문장이 붙고 반대 성별은 제외 태그로 들어갑니다. 메인 화면의 보컬 선택이 이 기본값보다 우선합니다), 곡 주제·제목(언어별), 태그(Treblo가 장르를 잡는 가장 강한 신호. 장르·하위 장르·시대·보컬 유형을 3~7개, 예: 1970s, soft rock, ballad, pop), 제외 태그, 배경 사진 검색어, 곡 길이도 같은 모달에서 바꾸고 저장하면 프리셋 파일에 기록됩니다. 복제해서 새 프리셋으로 자기만의 프리셋을 만들 수 있습니다.

✨ AI로 영어 프롬프트 자동 생성: 한국어 상세 설명만 적고 이 버튼을 누르면 메인 LLM(설정에서 고른 Claude·OpenAI·Gemini)이 장르·악기·BPM·보컬·질감을 담은 구체적인 영어 프롬프트를 써 줍니다. 체크를 켜 두면 Treblo 태그 사전에서 고른 태그·제외 태그, 배경 사진 검색어, 한·영·일 곡 주제 12개씩도 함께 채웁니다(비어 있는 칸만 채움). 상단 [설정]에 메인 LLM API 키가 필요합니다. 한 번 생성에 약 2~4천 토큰, 수십 원 수준입니다. 결과는 미리보기에서 확인하고 저장해야 반영됩니다.

곡 주제는 언어별입니다. 가사 언어를 English로 고르면 영어 주제 목록에서, 日本語면 일본어 목록에서 곡 제목을 뽑습니다. 그 언어의 주제가 비어 있거나 한국어뿐이면 앱에 내장된 언어별 기본 주제 6개를 씁니다. 유튜브 제목·트랙리스트·썸네일의 곡 수와 길이 표기("6곡 · 24분", "6 tracks · 24 min", "6曲 · 24分")도 가사 언어를 따릅니다.

[+ 새 프리셋] 버튼은 빈 상태에서 프리셋을 만듭니다. 프리셋 id(영문 소문자·숫자·하이픈), 이름, 한국어 상세 설명만 적으면 됩니다. 상세 설명에는 반드시 음악 장르·악기·템포·보컬을 적으세요(예: "1970~80년대 미국 컨트리 팝, 어쿠스틱 기타와 페달 스틸, 90 BPM, 따뜻한 남성 보컬"). 풍경이나 장면만 묘사하면 작곡 AI가 어떤 음악인지 알 수 없어 엉뚱한 곡이 나옵니다. 저장하면 메인 LLM 키가 있을 때 이름과 설명으로 영어 프롬프트·태그·제외 태그·곡 주제·배경 검색어를 자동 생성해 채워 주며(모달에 안내 표시), 키가 없으면 한국어 설명과 프리셋 이름이 그대로 전달됩니다. 저장하면 바로 선택되어 생성에 쓸 수 있고, 새로고침해도 마지막에 고른 프리셋이 유지됩니다.

보컬이 있는 장르(컨트리·트로트·발라드 등)를 만들려면 작곡 AI가 Treblo여야 합니다. Lyria가 활성이면 연주곡만 만들 수 있어 보컬 옵션이 자동으로 "연주곡"이 됩니다. 이때는 프롬프트에서 보컬 묘사를 빼고 "연주곡 편곡"으로 요청하며, 예상 칸에 ⚠ 경고가 뜹니다. 보컬이 빠진 연주곡은 원래 장르와 다르게 들릴 수 있으니(예: 올드팝 발라드 → 피아노·색소폰만 남아 재즈처럼) 프리셋을 평가할 때는 보컬로 만들어 보세요. 상단 [설정]에서 Treblo 카드의 [● 활성화]를 누르세요.

프리셋은 presets/*.json 파일입니다. 복사해서 name, prompt(영어 권장), topics(곡 제목·주제 목록, 언어별), length_range(초, 30의 배수), thumbnailStyle 등을 바꾸면 새 프리셋이 됩니다. 서버 재시작 없이 화면 새로고침으로 반영됩니다.

4-3. 간편하게 생성 (프리셋 없이 곡 설명만으로)

"새 플레이리스트" 제목 오른쪽 버튼의 아랫줄에 있는 ▶ 간편하게 생성을 누르면 모달이 열립니다. 만들고 싶은 곡을 한국어로 자유롭게 서술하고(예: "비 오는 밤 창가에서 듣는 잔잔한 어쿠스틱 발라드. 통기타와 피아노, 70~80 BPM, 담담한 여성 보컬, 이별 뒤의 그리움"), 소스·곡 수·가사 언어·보컬·배경·자막을 고른 뒤 [▶ 생성 시작]을 누르면 됩니다. 모달 안에 예상 크레딧이 표시되며 별도 확인 창은 뜨지 않습니다.

  1. 메인 LLM이 설명을 읽고 영어 프롬프트, Treblo 태그·제외 태그, 한·영·일 곡 주제, 배경 사진 검색어를 만들어 새 프리셋으로 저장합니다(10~30초, 모달에 진행 문구 표시). 프리셋 id는 quick-날짜-시각, 이름은 입력한 이름 또는 설명의 첫 구절(16자)이며 프리셋 목록에 ⚡ 표시로 나타납니다.
  2. 그 프리셋이 메인 화면에 선택되고 고른 옵션이 메인 폼에 반영된 뒤, [▶ 자동 생성 시작]과 같은 경로로 작업이 시작됩니다. 이후 진행·결과는 4-4와 같습니다.
설명에는 반드시 장르·악기·템포·보컬·분위기를 적으세요. 풍경·감정만 쓰면 작곡 AI가 어떤 음악인지 알 수 없습니다. 메인 LLM 키가 없거나 프롬프트 생성에 실패하면 Treblo·Lyria 소스는 시작하지 않습니다(한국어 설명이 그대로 전달되어 크레딧만 낭비되므로). 이때도 프리셋은 저장되므로 [설명·편집] → ✨ 버튼으로 다시 만들 수 있고, 테스트 소스는 키 없이 진행됩니다. Lyria 소스는 보컬을 "연주곡"으로 두어야 합니다. 만들어진 ⚡ 프리셋은 [설명·편집]에서 고치거나 지울 수 있고 다음에 다시 골라 쓸 수 있습니다. 썸네일 스타일·추가 프롬프트 같은 세부 옵션은 메인 화면에서 그 프리셋을 고르고 [▶ 자동 생성 시작]을 쓰세요.

4-4. 실행과 결과

  1. 옵션을 고르고 "새 플레이리스트" 제목 오른쪽의 ▶ 자동 생성 시작을 누릅니다(input 폴더·output 폴더 버튼도 그 옆). Treblo 소스는 크레딧 사용 확인 창이 뜹니다.
  2. 진행 상황은 작업 칸의 진행 바와 그 아래 로그에 표시됩니다. 6곡 기준 생성 5~10분 + 렌더링 수 분이 걸립니다.
  3. 완료되면 output/작업ID/에 다음이 생깁니다. 폴더명은 날짜_시각_프리셋명_곡수 형식입니다(예: 20261018_0030_올드팝클래식_6곡, 같은 이름이 있으면 뒤에 _2).

4-5. 배경 사진

분위기에 맞는 사진 고르기: 메인 LLM 키가 있으면 작업마다 (1) 프리셋 스타일 + 실제 곡 제목·가사(보컬곡은 각 곡 첫 여섯 줄)로 영어 사진 검색어 8개와 피할 소재를 짜고(background_plan.json에 저장), (2) 검색어 세 개로 모은 새 후보와 이미 저장된 풀 사진을 한 목록으로 놓고 제목·설명 기준으로 분위기에 맞는 순서를 매긴 뒤, (3) 위에서부터 새 사진은 내려받고 풀 사진은 그대로 씁니다. 로그에 기획 문장·검색어·선별 결과가 찍힙니다. 키가 없으면 프리셋의 검색어와 휴리스틱 점수(스톡 사진 소스·CC0 우선)로 고릅니다. 마음에 안 드는 사진은 프리셋 모달의 배경 사진 목록에서 제외하면 다시 쓰지 않습니다.

라이선스 정책(상업적 이용 가능만): 내려받는 사진은 CC0 · 퍼블릭 도메인 · CC BY · Pexels License만 허용합니다. NC(비영리)·ND(변경 금지)·SA(동일조건) 및 Wikimedia에 사용 제한(상표·초상권 등)이 기재된 파일은 후보에서 제외합니다. CC BY 사진은 출처 표기가 의무라서 유튜브 설명에 제목·작가·라이선스(링크)·출처 페이지가 자동으로 들어가며, 사진별 정보는 assets/backgrounds/프리셋/*.json에 남습니다. 인물·얼굴이 보이는 사진은 초상권 때문에 검색 단계에서 거릅니다(제목 기준이라 완벽하지는 않으니 업로드 전 한 번 확인하세요).

"배경" 옵션의 기본값은 무료 사진 슬라이드쇼입니다. 프리셋 분위기에 맞는 사진 여러 장(기본 8장, 영상이 짧으면 그만큼만)을 10초마다 페이드로 바꿔 가며 보여 줍니다. 사진이 영상보다 짧으면 처음부터 다시 반복되며, 마지막 장에서 첫 장으로도 페이드되어 끊김이 없습니다. 표시 시간·페이드 길이·사진 수는 설정에서 바꿉니다. 무료 사진 한 장 고정을 고르면 한 장만 씁니다.

시간 표시 · 날씨와 시간 배경: "배경"에서 시간 표시를 고르면 화면 가득 디지털 플립시계(시:분:초, 위에 날짜)가, 날씨와 시간을 고르면 위쪽에 주소지 부근의 현재 날씨(지역명·아이콘·기온·최고/최저·습도·바람)와 아래쪽에 시계가 표시됩니다. 고르는 순간 설정 모달이 열리고(선택 옆 [설정] 버튼으로 다시 열 수 있음) 다음을 정합니다: 바탕(배경 이미지 위에 표시 → 슬라이드쇼/사진 한 장/그라데이션 중 선택, 또는 단색 배경 → 색 선택), 주소(날씨용, 예: 서울특별시 강남구), 시간 형식(24시간/12시간), 초 표시, 시작 시각(비우면 렌더링 시점의 현재 시각). 값은 설정에 저장되어 다음 작업에도 쓰입니다. 영상의 시계는 시작 시각부터 영상 길이만큼 실제로 흘러가며(ffmpeg 가 프레임마다 시각을 찍음), 날짜 줄의 요일은 영문(Sun·Mon…)입니다. 날씨는 Open-Meteo(무료, 키 불필요)에서 렌더링 시점의 현재 날씨를 한 번 가져와 고정 표시하고, 출처가 유튜브 설명에 자동으로 들어갑니다. 주소를 못 찾거나 네트워크가 안 되면 경고 로그를 남기고 시계만 표시합니다. 테스트(mock) 작업은 네트워크를 쓰지 않고 표본 날씨를 그립니다. 썸네일에는 정지 시계(시작 시각)와 날씨 패널이 같이 들어갑니다.

사진은 프리셋 분위기에 맞는 검색어(예: 재즈 → 색소폰·바 카운터·빗속 도시)로 무료 사진을 받아 영상 배경과 썸네일에 씁니다. 사진은 assets/backgrounds/프리셋id/에 저장되어 다음 작업에서도 재사용되고, 매번 새 사진을 한 장씩 더 받아 풀을 늘립니다.

4-6. 플레이리스트 조합 (보관 곡 → 30·60분 영상)

한두 곡씩 만들어 둔 같은 장르의 곡을 모아 원하는 길이의 영상을 다시 만드는 기능입니다. 왼쪽 "기타 설정" 아래 ▶ 플레이리스트 조합…을 누르면 모달이 열립니다. 작곡 AI를 다시 부르지 않으므로 크레딧이 들지 않습니다(메인 LLM 키가 있으면 배경 사진 기획에 경량 모델만 씀).

  1. 프리셋(장르)을 고르면 그 프리셋으로 완료된 작업들의 곡이 아래 표에 나옵니다. "모든 프리셋"으로 섞을 수도 있습니다. 테스트(합성음) 곡은 기본으로 빠집니다.
  2. 목표 길이(30·60·90·120분 또는 직접 입력), 곡 순서(최신·오래된·무작위), 크로스페이드 초(기본 3, 0이면 무음 간격), 같은 제목은 한 번만을 정하고 [자동 선택]을 누르면 목표 길이까지 채워 줍니다. 표의 줄을 눌러 직접 넣고 뺄 수도 있고, 선택 곡 수와 총 길이가 위에 표시됩니다. 보관 곡이 모자라면 목표에 못 미친다는 안내가 뜹니다.
  3. 배경·가사 자막·썸네일 스타일·제목을 정하고 [▶ 조합 시작]. 정규화 → 크로스페이드 결합 → 자막 → 배경·썸네일 → 렌더링 → 유튜브 제목·설명·챕터까지 보통 작업과 같이 진행되며, 폴더명 끝에 _조합이 붙습니다.
원본 곡 파일은 복사하지 않고 원본 작업 폴더에서 바로 읽습니다. 조합 작업의 tracks/는 비어 있고 결과 정보가 원본 위치를 가리키므로, 원본 작업을 [삭제]하면 그 조합 결과를 다시 만들 수 없습니다(이미 만든 mp4는 남습니다). 가사 자막은 원본의 단어 정렬 데이터를 그대로 쓰며, 정렬이 없는 곡은 균등 배분이라 크로스페이드 구간에서 앞뒤 곡 가사가 잠깐 겹쳐 보일 수 있습니다.

4-7. 유튜브 업로드

왼쪽 아래 유튜브 업로드 패널에서 Google 계정을 연결하면 완료된 작업의 영상을 앱에서 바로 채널에 올릴 수 있습니다. 설명·태그·썸네일은 작업 결과(youtube.json, thumbnail.jpg)를 그대로 씁니다.

준비 (한 번만)

  1. Google Cloud 콘솔에서 프로젝트를 만들고 API 및 서비스 → 라이브러리에서 YouTube Data API v3를 사용 설정합니다.
  2. OAuth 동의 화면: 사용자 유형 외부, 앱 이름·이메일 입력. 테스트 사용자에 업로드할 채널의 Google 계정을 추가합니다. (범위는 따로 추가하지 않아도 됩니다. 연결 시 "확인되지 않은 앱" 경고가 뜨면 고급 → 이동으로 진행)
  3. 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID, 애플리케이션 유형은 반드시 데스크톱 앱. 만들어진 클라이언트 ID와 클라이언트 보안 비밀을 복사합니다.
  4. 앱의 유튜브 업로드 패널에 ID·비밀을 붙여 넣고 저장 → [Google 계정 연결]. Google 로그인 창에서 채널 계정을 고르고 권한을 허용하면 "연결 완료" 창이 뜨고 패널에 채널명이 표시됩니다.
연결은 서버 PC의 브라우저에서 localhost 주소로 접속했을 때만 됩니다(Google이 localhost로만 돌려보냄). 다른 PC(LAN 주소)에서는 연결 버튼이 안내만 띄웁니다. 연결 뒤의 업로드는 어느 PC에서든 할 수 있습니다. 토큰은 서버 PC의 config.json 에만 저장됩니다(git 제외).

업로드: 작업 목록에서 완료된 작업을 고르고 ▲ 선택한 작업 업로드…를 누르면 제목·설명·태그·공개 설정·예약 공개·썸네일·AI 생성 표시를 확인하는 모달이 열립니다. [▲ 업로드]를 누르면 진행 바와 로그에 상황이 표시되고, 끝나면 유튜브 링크가 모달과 결과 칸(▶ YouTube 버튼)에 나타납니다. 예약 공개를 지정하면 비공개로 올라가 그 시각에 자동 공개됩니다. 같은 작업을 다시 올리면 영상이 하나 더 생깁니다.

자동 업로드: 패널의 "작업이 완료되면 자동 업로드"를 켜 두면 생성이 끝나는 즉시 패널의 기본 공개 설정(기본 비공개)으로 올라갑니다. 테스트(합성음) 작업은 올리지 않습니다. Claude(MCP)에서는 upload_youtube 도구로 올릴 수 있습니다.

항목내용
할당량YouTube Data API 기본 10,000단위/일, 업로드 1건 1,600 → 하루 약 6건. 넘으면 "quotaExceeded" 오류가 나고 태평양 시간 자정에 초기화됩니다. 더 필요하면 Google Cloud에서 할당량 증가를 신청합니다.
썸네일전화번호 인증이 된 채널만 사용자 지정 썸네일을 설정할 수 있습니다. 인증이 안 된 채널은 영상은 정상 업로드되고 썸네일만 경고로 남습니다(유튜브 스튜디오에서 직접 설정).
AI 생성 표시유튜브의 "변경되거나 합성된 콘텐츠" 공개 항목(containsSyntheticMedia)을 켭니다. AI 음악이므로 켜 두는 것을 권장합니다.
7일 만료OAuth 동의 화면이 테스트 상태면 Google 정책상 연결(토큰)이 7일 뒤 만료되어 [다시 연결]이 필요합니다. 동의 화면을 프로덕션으로 게시하면 만료되지 않습니다(앱 인증을 받지 않아도 본인 사용은 가능하며 경고 화면만 뜹니다).
설정 위치클라이언트 ID·비밀·토큰·자동 업로드 설정은 config.json 의 youtube 항목. [연결 해제]는 토큰만 지웁니다.

6. 버튼 동작

🌙 / ☀ 다크·라이트 모드

상단 바의 달/해 버튼을 누르면 화면이 어두운 테마와 밝은 테마 사이에서 바뀝니다. 선택은 이 브라우저에 저장되어 다음 실행에도 유지되고, 로그 새 창을 열어 두었다면 거기에도 바로 함께 적용됩니다. 처음에는 다크 모드로 시작합니다.

종료

캐시 삭제 → 작업 프로세스(ffmpeg·python) 종료 → 포트 정리 → 이 프로젝트의 명령 창 닫기 → 브라우저 창 닫기 → 서버 종료 순서로 진행합니다. 브라우저가 자동으로 닫히지 않으면 탭을 직접 닫으세요. 서버 API: POST /api/shutdown

업데이트

앱을 켤 때 자동으로 GitHub 를 한 번 확인해 새 커밋이 있으면 버튼이 업데이트 N(녹색)으로 바뀌고 로그에도 한 줄 남습니다. 버튼에 마우스를 올리면 최근 변경 제목이 보입니다. 오프라인이면 조용히 넘어갑니다.

버튼을 누르면 GitHub 원격 저장소를 확인(git fetch)해 새 커밋이 있으면 목록을 팝업으로 보여 줍니다. 지금 업데이트를 누르면 git pull로 갱신하고 "업데이트 완료, 앱을 재시작하세요" 팝업이 뜹니다. package.json이 바뀐 경우 install.bat 재실행 안내가 함께 표시됩니다. 원격 저장소가 없으면 프로젝트 폴더에서 다음을 실행하세요.

git remote add origin https://github.com/계정/저장소.git
git push -u origin main

7. STOP.bat (비상 종료)

앱 화면이 멈췄거나 브라우저 창을 닫아 버려 [종료] 버튼을 누를 수 없을 때 프로젝트 폴더의 STOP.bat을 실행합니다.

  • 서버가 응답하면 [종료] 버튼과 같은 종료 API를 호출합니다.
  • 응답이 없으면 직접 정리합니다: 캐시 삭제, 이 프로젝트 경로가 명령줄에 포함된 node·ffmpeg·python 프로세스 종료, 이 앱이 점유한 포트 정리, 앱 브라우저 창과 이 프로젝트의 명령 창 닫기. 다른 프로그램은 건드리지 않습니다.

9. 문제 해결

증상조치
포트 5177 사용 중STOP.bat 실행 후 다시 START.bat. 또는 설정에서 포트 변경 후 재시작.
크레딧 확인 실패API 키 오타, 카드 미등록(체험 크레딧 미지급), 네트워크 차단 여부 확인.
생성 실패(FAILURE)크레딧은 차감되지 않습니다. 자동으로 1회 재시도하며, 계속 실패하면 프롬프트를 단순화해 보세요.
"… 소스는 대기 상태입니다"상단 [설정]에서 해당 소스의 ● 활성화를 누르세요. 작곡 AI 는 한 번에 하나만 활성입니다.
유튜브: "Google 연결이 만료되었거나 취소되었습니다"OAuth 동의 화면이 테스트 상태면 7일마다 만료됩니다. 패널의 [다시 연결]을 누르거나 동의 화면을 프로덕션으로 게시하세요.
유튜브: "quotaExceeded"오늘 API 할당량(기본 10,000, 업로드 1건 1,600)을 다 썼습니다. 태평양 시간 자정 이후 다시 시도하거나 Google Cloud에서 할당량 증가를 신청하세요.
유튜브: 연결 창에 "redirect_uri_mismatch" / "access blocked"OAuth 클라이언트 유형이 "데스크톱 앱"인지, 동의 화면의 테스트 사용자에 로그인한 계정이 있는지 확인하세요. 연결은 localhost 주소에서만 됩니다.
유튜브: 썸네일 설정 실패채널 전화 인증이 필요합니다. 영상은 올라갔으니 유튜브 스튜디오에서 thumbnail.jpg 를 직접 올리세요.
Lyria: "연주곡 프리셋에서만 쓸 수 있습니다"보컬 옵션을 "연주곡"으로 바꾸거나 연주곡 프리셋(로파이 스터디 등)을 고르세요.
Lyria: HTTP 400/403 오류키 오타, 결제 미연결 프로젝트(Lyria는 무료 티어 없음), 프롬프트에 실제 아티스트 이름이 들어가 안전 필터에 걸린 경우입니다. 프리셋의 영어 프롬프트에서 아티스트 이름을 지우세요.
Lyria: HTTP 429요청 한도 초과. 자동으로 재시도하며, 계속되면 설정의 Lyria 동시 생성 수를 1로 낮추세요.
자막 글자가 네모로 나옴설정의 자막 글꼴을 Malgun Gothic 또는 Noto Sans KR로 바꾸세요.
날씨 조회 실패 → 시계만 표시주소를 더 넓게(구·시 단위) 적거나 인터넷 연결을 확인하세요. 지오코딩은 OpenStreetMap(Nominatim), 날씨는 Open-Meteo 를 씁니다.
썸네일/배경이 생성되지 않음Python과 Pillow 설치 확인: python -m pip install pillow
다른 PC에서 접속 불가Windows 방화벽에서 Node.js 허용, 같은 네트워크인지 확인.
START/STOP.bat 실행 시 "...은(는) 내부 또는 외부 명령이 아닙니다" 오류배치 파일이 UTF-8로 저장된 경우입니다. 메모장에서 다시 열어 ANSI(CP949) 인코딩으로 저장하세요. cmd는 UTF-8 배치 파일의 한글 줄 뒤를 잘못 읽습니다.
[종료] 시 브라우저의 다른 탭까지 닫힘종료 절차는 창 제목에 앱 이름이 포함된 브라우저 창을 닫습니다. 앱 탭이 활성 탭인 창 전체가 닫히므로, 다른 작업 탭은 별도 창에서 쓰는 것을 권장합니다.
