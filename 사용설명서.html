플레이리스트 팩토리 사용설명서

장르 프리셋을 고르고 곡 수와 언어를 정한 뒤 ▶ 자동 생성 시작을 누르면, 곡 생성(병렬) → 라우드니스 정규화 → 이어붙이기 → 가사 자막 → 썸네일 → 1080p 영상 렌더링 → 유튜브 제목·설명·챕터 작성까지 한 번에 끝납니다. 음악 생성은 Treblo(구 Sonauto) API를 사용합니다. Powered by Treblo

1. 설치와 실행

  1. install.bat을 한 번 실행합니다. Node 패키지와 Pillow(Python)를 설치하고 ffmpeg 유무를 확인합니다.
  2. START.bat으로 실행합니다. 의존성이 없으면 install.bat을 자동으로 호출합니다. 브라우저가 자동으로 열립니다.
  3. 같은 네트워크의 다른 PC에서는 START 창과 화면 상단에 표시되는 http://IP주소:5177로 접속합니다. 접속이 안 되면 Windows 방화벽에서 Node.js의 사설 네트워크 접근을 허용하세요.
필수 프로그램: Node.js 18 이상, Python 3.10 이상(Pillow), ffmpeg(PATH 등록). ffmpeg 설치: winget install Gyan.FFmpeg

2. Treblo API 키 발급과 입력

  1. treblo.com/developers에서 계정을 만들고 API 키를 발급받습니다. 무료 체험은 카드 등록 후 3,000크레딧(약 30곡)이 제공되며, 이후 월 $11(200곡) 플랜 또는 종량제(100크레딧당 약 $0.06)입니다.
  2. 앱 화면 왼쪽 아래 설정 (API 키 · 렌더링)을 펼쳐 키를 붙여 넣고 설정 저장을 누릅니다. 키는 프로젝트 폴더의 config.json에만 저장됩니다(git 추적 제외).
  3. 크레딧 확인을 눌러 잔액이 표시되면 연결 성공입니다. 곡 하나에 100크레딧이 듭니다.
웹앱 무료 정책과 API는 다릅니다. treblo.com 웹에서 무료로 만들고 내려받은 곡은 소스를 "로컬 폴더"로 바꿔 input/에 넣으면 나머지 과정(결합·자막·썸네일·렌더링)을 그대로 자동 처리합니다. 다만 웹에서 만든 곡의 상업적 이용 조건은 Treblo 이용약관 8조(Outputs)를 직접 확인하세요. API로 만든 곡은 API 약관에 따라 소유권과 수익화가 허용됩니다.

4-2. 프리셋

프리셋에는 장르의 악기·템포·분위기가 음악 용어로 이미 들어 있어 고르기만 하면 됩니다. 한 플레이리스트의 모든 곡은 같은 프리셋을 써서 결이 흩어지지 않습니다. 기본 제공: 재즈 나이트, 네오소울 R&B, 하드록 드라이브, 로파이 스터디(연주곡), 시티팝 나이트, 어쿠스틱 발라드, 테토 무드.

프리셋 선택 옆 [설명·편집] 버튼을 누르면 모달이 열립니다. 여기서 한국어 상세 설명(분위기·악기·템포·보컬 톤)을 읽고 고칠 수 있고, "한국어 상세 설명을 곡 생성 프롬프트에 포함"이 켜져 있으면 그 내용이 영어 기본 프롬프트 뒤에 붙어 Treblo에 그대로 전달됩니다. 아래 "최종 프롬프트 미리보기"에서 실제로 보내질 문장을 확인하세요. 곡 주제·제목(언어별), 제외 태그, 배경 사진 검색어, 곡 길이도 같은 모달에서 바꾸고 저장하면 프리셋 파일에 기록됩니다. 복제해서 새 프리셋으로 자기만의 프리셋을 만들 수 있습니다.

프리셋은 presets/*.json 파일입니다. 복사해서 name, prompt(영어 권장), topics(곡 제목·주제 목록, 언어별), length_range(초, 30의 배수), thumbnailStyle 등을 바꾸면 새 프리셋이 됩니다. 서버 재시작 없이 화면 새로고침으로 반영됩니다.

4-3. 실행과 결과

  1. 옵션을 고르고 ▶ 자동 생성 시작. Treblo 소스는 크레딧 사용 확인 창이 뜹니다.
  2. 진행 상황은 가운데 진행 바와 오른쪽 로그에 표시됩니다. 6곡 기준 생성 5~10분 + 렌더링 수 분이 걸립니다.
  3. 완료되면 output/작업ID/에 다음이 생깁니다.
파일내용
playlist.mp41920×1080 영상(배경 + 곡 제목 오버레이 + 가사 자막). 유튜브에 바로 업로드.
playlist.mp3결합된 오디오(320kbps)
thumbnail.jpg1280×720 유튜브 썸네일

subs.ass, lyrics.txt자막 원본과 전체 가사
tracks/곡별 원본 오디오와 Treblo 응답(JSON)
가사 자막 타이밍: Treblo API가 돌려주는 단어 단위 정렬 데이터를 줄 단위로 묶어 사용합니다. 정렬 데이터가 없으면(연주곡, 정렬 실패, 로컬 파일) 가사 줄을 곡 길이에 균등 배분하며 로그에 경고가 남습니다.

4-4. 배경 사진

"배경" 옵션이 무료 사진 자동이면 프리셋 분위기에 맞는 검색어(예: 재즈 → 색소폰·바 카운터·빗속 도시)로 무료 사진을 받아 영상 배경과 썸네일에 씁니다. 사진은 assets/backgrounds/프리셋id/에 저장되어 다음 작업에서도 재사용되고, 매번 새 사진을 한 장씩 더 받아 풀을 늘립니다.

사진 소스키라이선스비고
Wikimedia Commons (기본)불필요CC0·퍼블릭도메인·CC BY만 사용 (BY-SA 제외)Unsplash 출처 스톡 사진 카테고리를 먼저 검색해 품질이 좋고 1~3초로 빠릅니다. CC BY 사진은 유튜브 설명에 출처 문구가 자동으로 들어갑니다.

  • 사람이 찍힌 사진, 지도·문서·건물 기록물은 제목과 분류로 걸러내지만 완벽하지 않습니다. 결과 폴더의 background.png를 확인하세요.
  • 마음에 안 드는 사진은 assets/backgrounds/프리셋id/에서 지우고, 다시 받지 않게 하려면 그 사진의 .json에 있는 id를 assets/backgrounds/_rejected.txt에 한 줄 추가합니다. API: DELETE /api/backgrounds/프리셋id/파일명.jpg
  • 미리 여러 장을 받아 두려면: node scripts/fetch-backgrounds.js 4 (프리셋당 4장). 모음 이미지로 확인: python scripts/contact-sheet.py 확인.jpg
  • 검색어는 프리셋 JSON의 imageQueries에서 바꿀 수 있습니다. 영어로 2~3단어가 가장 잘 맞습니다.

6. 버튼 동작

종료

캐시 삭제 → 작업 프로세스(ffmpeg·python) 종료 → 포트 정리 → 이 프로젝트의 명령 창 닫기 → 브라우저 창 닫기 → 서버 종료 순서로 진행합니다. 브라우저가 자동으로 닫히지 않으면 탭을 직접 닫으세요. 서버 API: POST /api/shutdown

업데이트

GitHub 원격 저장소를 확인(git fetch)해 새 커밋이 있으면 목록을 팝업으로 보여 줍니다. 지금 업데이트를 누르면 git pull로 갱신하고 "업데이트 완료, 앱을 재시작하세요" 팝업이 뜹니다. package.json이 바뀐 경우 install.bat 재실행 안내가 함께 표시됩니다. 원격 저장소가 없으면 프로젝트 폴더에서 다음을 실행하세요.

git remote add origin https://github.com/계정/저장소.git
git push -u origin main

7. STOP.bat (비상 종료)

앱 화면이 멈췄거나 브라우저 창을 닫아 버려 [종료] 버튼을 누를 수 없을 때 프로젝트 폴더의 STOP.bat을 실행합니다.

  • 서버가 응답하면 [종료] 버튼과 같은 종료 API를 호출합니다.
  • 응답이 없으면 직접 정리합니다: 캐시 삭제, 이 프로젝트 경로가 명령줄에 포함된 node·ffmpeg·python 프로세스 종료, 이 앱이 점유한 포트 정리, 앱 브라우저 창과 이 프로젝트의 명령 창 닫기. 다른 프로그램은 건드리지 않습니다.

9. 문제 해결

증상조치
포트 5177 사용 중STOP.bat 실행 후 다시 START.bat. 또는 설정에서 포트 변경 후 재시작.
크레딧 확인 실패API 키 오타, 카드 미등록(체험 크레딧 미지급), 네트워크 차단 여부 확인.
생성 실패(FAILURE)크레딧은 차감되지 않습니다. 자동으로 1회 재시도하며, 계속 실패하면 프롬프트를 단순화해 보세요.
자막 글자가 네모로 나옴설정의 자막 글꼴을 Malgun Gothic 또는 Noto Sans KR로 바꾸세요.
썸네일/배경이 생성되지 않음Python과 Pillow 설치 확인: python -m pip install pillow
다른 PC에서 접속 불가Windows 방화벽에서 Node.js 허용, 같은 네트워크인지 확인.
START/STOP.bat 실행 시 "...은(는) 내부 또는 외부 명령이 아닙니다" 오류배치 파일이 UTF-8로 저장된 경우입니다. 메모장에서 다시 열어 ANSI(CP949) 인코딩으로 저장하세요. cmd는 UTF-8 배치 파일의 한글 줄 뒤를 잘못 읽습니다.
[종료] 시 브라우저의 다른 탭까지 닫힘종료 절차는 창 제목에 앱 이름이 포함된 브라우저 창을 닫습니다. 앱 탭이 활성 탭인 창 전체가 닫히므로, 다른 작업 탭은 별도 창에서 쓰는 것을 권장합니다.
